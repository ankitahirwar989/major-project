STEP 0b: SUBJECT LINKAGE (critical, make it a config switch)
The four sources come from different cohorts, so the same person is
usually NOT present in every modality. Implement
  linkage_mode: {true_id | pseudo_pair}
- true_id: inner-join on a shared subject ID. Report the overlap size per
  modality combination. Use this whenever overlap is adequate.
- pseudo_pair: build "virtual subjects" by pairing random samples of the
  same class (AD with AD, Non-AD with Non-AD) across modalities, with a
  fixed seed. Pair AFTER the subject-level train/test split, within each
  split, so no real subject crosses a split. Print a prominent warning that
  pseudo-paired fusion results demonstrate the method only, are NOT
  clinical evidence, and are inflated by construction because the class
  label is shared across modalities.
- Always also report unimodal results on each modality's FULL native dataset
  (no pairing), because these are the trustworthy numbers.

STAGE 2: PREPROCESSING (complete code)
- MRI: skull-strip/normalize to MNI, resample to 96x96x96 (or 2D slices),
  intensity normalization, augmentation. If the repo already provides
  preprocessed arrays, reuse them and document it.
- PET: co-register to MRI, SUVR (cerebellum reference), same resizing.
- Clinical: MMSE, CDR, ADAS-Cog, age, sex, education etc. Impute
  (median/KNN), scale, encode. EXCLUDE every label-leaking feature (the
  diagnosis itself and diagnosis-derived fields, e.g. CDR-based group labels
  if they define the label). List the excluded columns in the log.
- EEG: band-pass 0.5-45 Hz, notch, ICA artifact removal, epoching; features
  (band power, spectral entropy, coherence) AND raw epochs for deep models.
  Split by subject, never by epoch.
- CSF_GEN: as specified in Step 0.

STAGE 4: TRAINING & EVALUATION (identical for all 50)
- Subject-level, group-aware stratified 5-fold CV plus a held-out test set;
  fixed seed. Use StratifiedGroupKFold on subject ID.
- Optuna tuning inside training folds only.
- Class imbalance: class weights/SMOTE on train only.
- Scalers/imputers/feature selection fit on train folds only.
- Threshold chosen on validation data only (Youden's J); also report at 0.5.
- Metrics: Accuracy, Balanced Acc, Precision, Sensitivity, Specificity, F1,
  AUC-ROC, AUPRC, MCC, Brier, confusion matrix, ECE + reliability diagram.
- Mean +/- std across folds. Save out-of-fold P(AD) and embeddings.
- Log training time, parameter count, inference time.

STAGE 5: FUSION (from stored out-of-fold outputs)
